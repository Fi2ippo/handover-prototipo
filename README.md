# HANDOVER

Un sito per studenti che vogliono fare o stanno facendo l'Erasmus. Accompagna lo studente in sei momenti,
dalla scelta della meta fino al rientro: *Dove posso andare?*, *Quale fa per me?*, *Candidatura*,
*Preparazione*, *Vivere lì*, *Rientro e racconto*.

L'idea: mettere accanto alle informazioni ufficiali (UE, ESN, università) i racconti di chi c'è stato davvero,
per città, università e corso, non per paese.

## Prototipo universitario

Progetto del corso "Creación y Gestión de Empresas Informativas", Universidad de Málaga.
È un **prototipo**: **tutti i dati sono fittizi** e servono solo a mostrare come funziona l'interfaccia.
Sono pronti i momenti 01 (mappa delle mete) e 02 (quiz e confronto delle mete); i momenti 03–06 sono in sviluppo.

## Come aprirlo

- **Online**: dall'indirizzo di GitHub Pages indicato nella descrizione del repository.
- **Sul proprio computer**: aprire la cartella in VS Code e avviare `index.html` con l'estensione **Live Server**.
  Con il doppio clic sui file il browser blocca la lettura dei dati (`dati/*.json`).

Pensato per schermi desktop (1440 px). HTML, CSS e JavaScript, senza framework.
La mappa usa d3 e topojson, caricati da internet.
